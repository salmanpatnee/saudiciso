# User Onboarding: Password Update Requirement

## Overview
As part of our security measures, new users are required to update their password upon their first login to the CISO 360 GRC System.

## What to Expect
1. After logging in for the first time, you will be redirected to the profile update page
2. You will see a mandatory password update form
3. You must enter your current password and create a new password that meets our security requirements
4. Once you successfully update your password, you can access all application features

## Password Requirements
Your new password must meet the following security requirements:
- At least 8 characters in length
- Contain at least one special character (!@#$%^&*()_+-=[]{}|;:,.<>?)
- Contain at least one number
- Be different from your current/previous password
- Match the confirmation field

## Need Help?
If you encounter any issues during the password update process, please contact your system administrator.

## Security Reminder
Please choose a strong, unique password that you don't use for other accounts. Never share your password with others.
